# GV2 Model Flashing

Helper scripts live in the GV2 folder:

```text
gv2/build_gv2_image.ps1
gv2/flash_gv2.ps1
```

GV2 firmware, image tooling, xmodem flashing helper, and active model files are isolated in the local tree:

```text
gv2/firmware/
```

Active YOLO11 model files:

```text
gv2/firmware/model_zoo/tflm_yolo11_od/gv2-yolo11n-vespa-2026-02v1.tflite
gv2/firmware/model_zoo/tflm_yolo11_od/gv2-yolo11n-vespa-2026-05top.tflite
```
